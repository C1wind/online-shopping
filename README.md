## 目录结构

```
index.html              # 入口页面
css/app.css             # 样式
js/app.js               # 业务逻辑（商品/购物车/订单/后台）
js/analytics.js         # 大数据分析与推荐模块（课程设计新增）
js/serve.js             # 可选：局域网静态服务（手机访问用）
assets/vendor/          # ECharts 5（本地化，离线可用）
assets/products/        # 商品图片
```

## 快速开始

**电脑预览**：直接打开 `index.html`，或：

```bash
node js/serve.js
# 浏览器打开 http://127.0.0.1:8765
```

**手机访问**（与电脑同一 Wi‑Fi）：

```bash
node js/serve.js
# 手机浏览器打开 http://电脑局域网IP:8765
```

## 功能

**顾客**：注册 / 登录 / 注销，商品浏览搜索分页，购物车，结算付款，发货确认邮件（站内模拟），订单历史；未登录可浏览

**商家（店长）**：商品增删改 / 上下架，图片上传，**类别管理（增删商品类别）**，订单管理，销售统计（ECharts 图表 + 库存报表），**用户浏览/购买日志（本店范围）**，邮件日志

**平台管理员（admin）**：在店长能力之上额外拥有——
- **数据分析仪表盘**：KPI 总览、实时销售监控（±2σ 区间判定 + 低库存预警）、
  销售趋势（日/周/月）与线性回归预测（7 日移动平均 + 剔除异常点的稳健拟合，
  输出 MAE / MAPE / R²）、销售异常判别（z-score）、商品销售排行榜（按销量/销售额）、
  **用户画像**（地域分布 / 购买力分层 / 偏好分类）
- **日志审计**：登录日志（时间/IP/成败）、浏览行为（类别/停留时长/IP）、操作日志（时间/内容/IP/账号），支持 CSV 导出
- **人员管理**：销售人员 ID 添加/删除、密码重置
- 订单 / 商品数据 CSV 导出

**推荐系统**：
- 简单推荐：商品详情页"浏览过此商品的人也买了"（购买共现计数）
- 协同过滤：详情页"看了又看"（基于物品的余弦相似度），
  首页"猜你喜欢"（登录用户个性化推荐，基于交互矩阵的相似度累计）

**数据说明**：纯前端演示环境，浏览器无法获取真实公网 IP 与地理位置，
IP / 地域为首次访问生成的模拟值；首次打开自动生成近 90 天演示数据
（上升趋势 + 周末高峰 + 两次大促异常点），供分析与推荐算法开箱即用。

数据保存在浏览器 `localStorage`，刷新不丢。
